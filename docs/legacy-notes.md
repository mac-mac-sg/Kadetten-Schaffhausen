# Kadetten automatic updates
Owner-private Site. POST /api/refresh accepts public source content: {matchHtml,tableHtml,posts,shvData}. Writes additionally require owner identity or the configured automation credential. Use get_site's service token only in memory and hidden stdin; never in files, logs or client code. GET /api/data reads the persistent R2 snapshot.

Fetch Kadetten matchcenter and homepage externally for scheduled runs; direct Worker access is rejected by the source. Load WordPress posts since June 2026, paging until fewer than 100 posts, at most 20 pages; abort if exceeded. Manual refresh reads the WordPress REST pages (slug matchcenter and home) and posts through their verified public CORS interface in the owner's browser, then sends the content to the private endpoint.

Player season values use the public SHV MatchCenter GraphQL endpoint and the query in server/shv.mjs, team 41473, season 2026/27, QHL only. The schedule fetches this response externally as shvData. Manual refresh also requests SHV on the server. Validate season, team, roster, player metrics and total player goals equal the official team total. Stable SHV player IDs map to squad shirt numbers. Unknown or absent players stay unavailable, never zero-filled. Currently 19 mapped players. SHV includes report appearances, goals, field/7m goals, warnings, two-minute penalties and disqualifications; no keeper parades or shooting efficiency. European League remains a dated single-match snapshot.

Each source validates independently; failure preserves its prior records and successful timestamp. Snapshots: BUCKET kadetten/current.json and kadetten/previous.json. Read back checkedAt, status of games/table/news/players and counts. Retry transient external failures once. No rebuild is needed for data updates.

Build: node scripts/build.mjs. UI assets: dist/client. Worker source: server/worker.mjs + server/update.mjs + server/shv.mjs. Initial fallback: server/seed.json.

### Matchday, Saisonreise und Offline-Nutzung
Matchday nutzt das Datum in Europe/Zurich und die örtliche Anspielzeit mit Sommer-/Winterzeit. Am Spieltag erscheinen Countdown, Heute-Markierung und Anreise. Nur ein bestätigter, höchstens 90 Sekunden alter Online-Feed wird als live angezeigt. Ein bestätigtes Endresultat wandelt den Startseitenblock in einen Rückblick um. Während eines Spieltags aktualisiert eine sichtbare App ihren Datenstand alle zwei Minuten; außerhalb davon bleibt der bestehende Update-Ablauf erhalten.

Die Saisonreise unter der Tabelle zeigt je gewähltem Wettbewerb die vollständige erfasste Ergebnisfolge, kumulierte Tordifferenz, Siegesserien und eine chronologische Zeitlinie mit Derby-/Europacup-Markierungen. Historische Tabellenstände werden nicht rückwirkend geschätzt.

Der Service Worker speichert die App-Hülle und den zuletzt erfolgreich abgerufenen Datenstand lokal auf dem Gerät. Besuchte lokale Bilder sowie bis zu 80 öffentliche Kadetten-Newsbilder werden mitgespeichert; noch nicht geladene Bilder und externe Originalartikel sind offline nicht verfügbar. Offline-Daten erhalten einen Zeitstempel-Hinweis, Live-Daten werden niemals aus dem Cache angezeigt. Beim Wiederverbinden wird der Stand erneut geladen. Login-Seiten werden nicht als App gespeichert; 401/403 oder Login-Weiterleitungen löschen den App-Cache. Zugang und serverseitiger Datenschutz bleiben unverändert. Bei der ersten Nutzung ist eine Online-Verbindung erforderlich.

Design: feste Tabellenüberschrift im scrollbaren Tabellenbereich, markierte Kadetten-Zeile, dezente Gegnerfarben auf Matchdetails, sanfte Newsbild-Tiefe und ein kurzer Lichtakzent bei bestätigten Siegen; reduzierte Bewegung wird respektiert.

Live news banner: GET /api/live polls SHV and the official EHF European League feed independently. EHF source: https://ehfel.eurohandball.com/umbraco/api/livescoreapi/GetLiveScoreMatches/138790. Match exact Kadetten ID uyEpUicNjwv8hCX9B7A3sg, men 2026/27 match URL and explicit isLive flag; never infer live from kickoff or substitute missing scores with zero. App checks while News is visible, every 30s live and 60s otherwise. A source failure does not suppress a confirmed match from the other source. Server cache is 20s; client hides live data older than 90s.

### Spielvorschau und Formkurve
Die Vorschau enthält Spieldatum und Anspielzeit sowie einen Tabellenvergleich mit Teamlogos. Aufgebote bleiben auf abgeschlossene Spiele beschränkt. Der Teamschalter zeigt Ergebnisse aus Sicht des gewählten Teams (Sieg/Unentschieden/Niederlage). `/api/recent-games?team=…` lädt die letzten fünf abgeschlossenen QHL-Saisonspiele aus dem offiziellen SHV-Matchcenter, mit fünf Minuten Cache und Team-ID-Abgleich über den Kadetten-Spielplan. Bei Fehlern bleiben lokal erfasste Resultate mit Hinweis sichtbar. Für Europacup-Gegner wird die unvollständige lokale Historie ausdrücklich gekennzeichnet.

### Formkurve, Direktvergleich und Saisonübersicht
Spielvorschau/Statistik: beide Team-Formkurven (ältestes links, neuestes rechts), Teamwechsel für detaillierte letzte Spiele und direkte QHL-Duelle. `/api/head-to-head` prüft das Gegnerteam gegen den aktuellen Kadetten-QHL-Spielplan und lädt über den offiziellen SHV-Club-Spielplan die Saisons 2024/25 und 2025/26 zusätzlich zur aktuellen Saison. Nur QHL-Partien zählen: identische Juniorenteamnamen werden ausgeschlossen. Bis zu fünf jüngste abgeschlossene Duelle; fünf Minuten Cache. EHL-Historien bleiben als unvollständig markiert. Unter der Tabelle berechnet Saison in Zahlen je Wettbewerb Heim-/Auswärtsbilanz, S/U/N, Torbilanz, Durchschnitte und höchste Siege aus verifizierten abgeschlossenen Saisonspielen. Keine Testspiele und keine erfundenen historischen Tabellenstände.

### Archivierte QHL-Spielberichte
`dist/client/assets/game-reports.json` enthält verifizierte SHV-Spieldetails der acht abgeschlossenen QHL-Spiele bis 26.09.2026. Abruf über `game`, `gamePlayerStats` und `gameTeamStats` im offiziellen Matchcenter. Fixture-Datum, Saison, Kadetten-Team-ID und Resultat sowie Torsummen beider Aufgebote sind geprüft. UI lädt die Datei nur auf abgeschlossenen QHL-Spieldetails. Mannschaftsstatistiken, Halbzeiten, beide Aufgebote, Wurf-/Siebenmeterwerte, Strafen, Torhüterwerte, Zuschauer und Schiedsrichter. Null/Leerwerte bleiben unbekannt. Kaderlisten bestätigen keine Einsatzdauer. Teamstrafen beinhalten Offizielle. Offline wird die besuchte Datei wie andere lokale Assets gespeichert. Änderungen am Archiv benötigen eine neue Veröffentlichung; der normale News-/Spielplan-Update schreibt es nicht um.

### Schreibzugang
`POST /api/refresh` rejects unauthorized calls before reading any body or storage. Browser access requires dispatch-verified `oai-authenticated-user-id` plus owner email from runtime `KADETTEN_OWNER_EMAIL`. `GET /api/access` returns only the browser update permission. The refresh button is hidden by default and shown only to the owner. Anonymous viewers and other signed-in viewers cannot update. Origin checks additionally reject cross-origin writes.
Unattended updates obtain `siwc_bypass_bearer_token` via owner Sites `get_site`, keep it in memory and use it both as `OAI-Sites-Authorization: Bearer ...` (private platform access) and `X-Kadetten-Update-Key` (app write authorization). Only the SHA-256 digest is stored as secret runtime `KADETTEN_UPDATE_KEY_SHA256`; never include credentials in code, logs or prompts. If the platform service credential changes, the owner must update this secret digest and deploy before unattended writes work again; fail closed on 403 and report rather than weaken authorization. The scheduled task preserves audience.
